Slide 02 — Architecture & Flow
How AI Bug Logger Works
A two-phase async pipeline that beats the 30-second Google Chat webhook deadline while supporting full video analysis.

Phase 1 — Inline (≤ 25s)
Synchronous. Bucket routing (Python regex + fuzzy), RAG retrieval (top-5 similar tickets), text analysis via Gemini. Returns immediate response for text-only bugs, or an acknowledgment if media is present.
Phase 2 — Async Background (15–50s)
Background task. Downloads media via Google Chat API, OpenCV extracts 1 frame/sec (max 20 frames, 480px), sends frames to Gemini for enriched analysis. Three fallback paths guarantee a ticket is always created.
34 Projects
Auto-routed by bucket_router.py using tag matching, free-text scoring, and device detection.
606 Training Tickets
RAG retrieves the 5 most relevant real tickets as few-shot examples per query.
11 Fields Auto-Filled
Title, steps, priority, bug type, environment, device, OS, and more — all AI-extracted.
3 Fallback Paths
Truncation, timeout, and default-stuffing all gracefully degrade to Phase 1 result.
